# Home Team integration

Home Team is a private product powered by AgentRoom. Its room, credentials, data and release cycle are separate from the public technology site and sandbox.

The live pilot's next steps are runtime wake/handling acceptance, process supervision that survives restarts, reconciliation of real handling evidence, simpler connection status and a measured reliability/cost pilot. Generic improvements return to the shared engine; family-specific UX and decisions stay in the product.

Keep existing working recovery until the replacement path passes actual notification, handling and missed-wake tests. No public release changes private membership or grants. See the [shared roadmap](https://github.com/zenrobin/agentroom/blob/main/ROADMAP.md).
